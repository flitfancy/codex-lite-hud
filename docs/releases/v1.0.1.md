Codex Lite HUD 1.0.1 试用版修复部分本机会话显示“待识别”，并完善 Plus、Free、Pro 的额度读取和显示。

- 会话识别合并本地索引和只读数据库标题，补全新对话与重命名；同名且无法区分时仍要求手动固定，避免显示错会话。
- 同时记录 5 小时和周额度时分行显示各自的剩余比例。只记录一个有效窗口时只占一行，窗口过期后自动收起多余行。
- 兼容两种额度字段命名；异常窗口不再中断会话统计，缺失额度显示“—”，不把额外 credits 推算成订阅百分比。
- 安装脚本增加 `-WithCodex`，可创建 `Codex + HUD` 联合快捷方式，从一个入口启动两者，不增加常驻监听。

下载 Assets 中的 `codex-lite-hud-1.0.1-win-x64.zip`，解压后双击 `CodexLiteHud.exe`。GitHub 自动生成的 Source code 是源码包，不是可运行的安装包。

需要联合快捷方式时，在解压目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install-shortcuts.ps1 -WithCodex
```

脚本只创建快捷方式，完成后双击桌面的 `Codex + HUD` 启动。升级请先退出旧悬浮条，在原目录替换程序与脚本，保留自己的 `data/` 设置。

本地完整回归、干净 ZIP、SHA-256 与全新解压运行检查通过；已对真实的索引缺项会话完成识别重放并更新本机运行副本。额度兼容新增 17 个用例、额度显示新增 8 个用例，均为生成记录；Free/Plus 的真实账号现场验收仍待完成。

继续以 Pre-release 发布。现场验证环境为 Windows 11 x64、.NET Framework 4.8 系列和本机 Codex Windows 桌面客户端。HUD 只读本地记录，不联网、不读取登录密钥；额度仍是本地快照，其他系统和客户端版本需独立验证。
