Codex Lite HUD 1.0.4 试用版（2026-10-23）将额度旁容易误解的“7天”改为距离实际重置时间的倒计时。

- 标题为“剩余/重置”，例如 `7%/4.7天` 表示当前剩余 7%，约 4.7 天后重置；紧凑模式显示 `7%/4.7d`。倒计时来自本机日志记录的实际重置时间。
- 没有新额度快照时，倒计时也会随常规刷新更新；缺少重置时间显示 `7%/—`，不按套餐或窗口长度猜测。
- Plus 同时记录短周期和周额度时，继续分行显示各自的剩余比例和重置倒计时；只有一个有效窗口时不预留第二行，窗口过期后收起对应行并等待新记录。

下载 Assets 中的 `codex-lite-hud-1.0.4-win-x64.zip`，解压后双击 `CodexLiteHud.exe`。Source code 是源码包。升级时先退出旧 HUD，替换原目录中的程序与脚本，保留自己的 `data/` 设置。

额度显示 11 项、套餐兼容 17 项、字体拟合 7 项回归通过，完整隔离回归 25 组通过，0 失败、0 跳过；干净 ZIP 文件集、SHA-256 与解压后运行检查通过。

小屏幕布局策略沿用上一版，包含双额度、紧凑布局、多 DPI 和模拟小桌面检查；极小可用高度下仍会缩小字号，尚未增加按重要性自动收起指标的功能。Free 与 Plus 的验证使用生成记录，真实账号现场验收仍待完成。账号剩余比例仍来自本地日志快照，不能视为实时服务器查询。

继续以 Pre-release 发布，不设为 Latest 稳定版。现场验证范围为 Windows 11 x64、.NET Framework 4.8 系列和本机 Codex Windows 桌面客户端；其他系统与客户端版本需要独立验证。
