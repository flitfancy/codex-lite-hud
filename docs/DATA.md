# 数据与统计

## 读取范围

`CODEX_HOME` 或默认 `%USERPROFILE%\.codex` 下：

- `session_index.jsonl`：会话 ID 与名称，按文件元数据变化缓存。
- `sessions/`、`archived_sessions/`：增量读取日志中的统计记录。
- 最新编号的 `state_*.sqlite`：使用 Windows `winsqlite3.dll` 只读查询 ID 与归档状态，区分同名会话。数据库结构不兼容时不写入、不猜测。

当前窗口选中项来自 Windows UI Automation。只显示能够可靠对应到本机日志的聊天；多个未归档同名项仍需手动固定。

## HUD 自己的文件

`portable.flag` 存在时，保存到程序旁的 `data/`；否则保存到 `%LOCALAPPDATA%\CodexLiteHud`。`CODEX_LITE_HUD_DATA_HOME` 可以覆盖该路径。

- `position.json`：锁定状态、侧栏底部间距和解锁后的主窗口相对位置；兼容旧版仅保存底部间距的文件。
- `display.json`：显示项目、顺序和布局版本；首次运行仅隐藏模型。旧布局迁移为新默认顺序，独立“上次入/出”并入输入和输出；之后显式开启模型的选择会保存。
- `session.json`：自动/固定模式，以及固定会话的 ID。
- `status.json`：运行位置、目标窗口、最近读数和识别状态，可能包含会话名。

这些是运行数据，不进入源码或发行包。HUD 不读取 `auth.json`，不连接网络，不发送模型请求，不改写 Codex 的配置、会话和数据库。

## 读数边界

输入和输出各显示两行：“本次”为最近一次已记录模型请求，“对话”为本会话累计，不累计整轮中的多次请求。输入包含缓存，输出包含推理；上下文只取最近记录的单次请求输入加输出。HUD 与菜单的悬停提示已移除。`tok/s` 的分母包含等待，不能当作服务器纯解码速度。

账号额度按本地记录时间取较新快照。启动时只检查会话日志文件元数据，读取最近修改的至多 16 个日志的末尾 256 KiB；之后记住各日志读取位置，通过文件变化通知只读取新增字节，保留尚未完成的半行，截断或替换后重新定位。游标缓存最多保留 128 个文件，普通大段工具输出不整行保留。30 秒补查近期目录元数据。扫描范围仅为 `sessions/` 与 `archived_sessions/`，不读取认证文件。后台聊天写入的新快照也可更新额度，不必切换会话；但服务器没有写入新快照时无法得到即时额度。多个窗口显示剩余最少的一项；到重置时间后移除过期值，等待新记录。快照原始时间保留在本机诊断状态中。

缓存占比为累计缓存输入除以累计输入，不是本次请求的命中率。模型、上次请求输入/输出与请求耗时来自现有日志；缺失时显示“—”，不推算价格或服务器解码耗时。

轮次按 `event_msg/task_started` 的 `turn_id` 去重，完成与中止读取相同 ID 的结束事件；工具调用、页面上下文及同轮补充输入不另起轮。缺少可识别的开始事件时显示“—”，不按用户角色消息数猜测。压缩只统计顶层 `compacted` 成功记录，优先按压缩响应 ID 去重，缺失时用窗口 ID 或记录条数；不会遍历摘要的替换历史来增加计数。它们反映本文件保留的记录，不能补回缺失或未继承的历史。

时间分别显示“用时”和“跨度”，每项独立分行放大，使用 s、m、h 或 d 缩写；请求耗时位于两项时间上方。累计运行优先使用轮次结束记录的 `duration_ms`，否则以开始/结束时间计算；尚未结束的轮次从开始计到本次读取，包含工具、模型和交互等待，结束后停住。重复轮次事件不重复相加。跨度从当前文件最早的时间记录计算到本次读取，包含两轮之间和会话停留的时间。时间戳支持日志中的 Unix 秒、毫秒与带时区日期文本；日志没有相应记录时显示缺失，不推断未保留的历史。
