Codex Lite HUD 1.0 公开试用版，是一个独立的 Windows 会话用量悬浮条，把当前聊天的统计放在 Codex 导航栏头像上方。

- 输入和输出各自显示最近请求与对话累计；上下文下面依次为轮次/压缩、缓存占比；请求耗时在用时与跨度上方，两项时间分行放大。默认显示 9 个区块，模型可从右键菜单开启。
- 轮次与成功压缩次数按当前日志的原生事件和 ID 去重；右键选择显示数据与顺序，HUD 和菜单无悬停提示。
- 顶部 CLH 标题与动态名称高度；时间显示为累计运行/会话跨度，位置默认锁定，解锁后自由拖动。
- 多行名称、动态尺寸、统一菜单主题与原生窗口事件跟随；切换其他应用仍随主窗口保留，宠物窗口不会改变目标。
- 只读本机 Codex 记录，支持自定义目录，便携数据与公共程序分开；无需 Magpie 或额外模型调用。
- FlitFancy MIT 许可，Windows x64 ZIP 附 SHA-256 校验。

本地隔离回归和发行文件集检查通过。首版现场验证范围为 Windows 11、.NET Framework 4.8 系列及本机 Codex Windows 桌面客户端；其他系统与后续 Codex 内部格式仍需独立验证。账号额度是日志快照，速度包含请求等待时间。

本版以 GitHub Pre-release 发布，EXE 尚未数字签名。问题反馈请通过仓库 Issues 提交，并附 Windows 与 Codex 版本、复现步骤和经过脱敏的截图。
