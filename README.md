# Codex Lite HUD

**把当前会话的用量留在 Codex 侧边栏。**

[English](README-EN.md) · [首次使用](first-run.md) · [更新记录](CHANGELOG.md) · [发布包](https://github.com/flitfancy/codex-lite-hud/releases)

Codex Lite HUD 是一个 Windows 悬浮条。打开 Codex 后，在头像上方看当前会话的输入、输出、上下文占用、累计运行时间、会话跨度、轮次、压缩、请求均速和账号剩余额度，切换会话时跟着更新。

当前版本为 **1.0**。程序直接读取本机 Codex 记录，普通用户权限运行，不需要 Magpie、Node.js 或 Python。

## 开始使用

从 Releases 下载 `codex-lite-hud-1.0-win-x64.zip`，解压到一个可写、方便保留的位置，双击 `CodexLiteHud.exe`。需要快捷方式或登录启动时，按[首次使用](first-run.md)设置。

首版已在 Windows 11 x64、.NET Framework 4.8 系列和 Codex Windows 桌面版上验证。Windows 10 与其他客户端版本尚需独立兼容验证；CLI、远程机器和没有本地日志的聊天不在首版验证范围内。

## 能看到什么

| 读数 | 口径 |
| --- | --- |
| 输入 | 单位为 token；“本次”为最近一次已记录请求，“对话”为本会话累计；均包含缓存输入 |
| 输出 | 单位为 token；“本次”为最近一次已记录请求，“对话”为本会话累计；均包含推理 token |
| 上下文 | 最近一次已记录请求的输入加输出，占日志所报窗口容量的比例 |
| 用时/跨度 | 用时与跨度分别显示，数字分行放大；分别为累计运行和从首条记录至当前的跨度 |
| 轮次/压缩 | 按 `turn_id` 去重的 Codex 轮次，以及顶层成功压缩记录数 |
| tok/s | 最近完成请求的输出 token ÷ 请求耗时，包含等待，属于请求均速 |
| 剩余额度 | 本机日志中的账号额度快照；多个窗口时显示剩余最少的一项 |
| 模型 | 最近记录的模型名称，默认隐藏，可右键开启 |
| 缓存占比 | 累计缓存输入占累计输入的比例 |
| 请求耗时 | 最近一次已记录请求的耗时，包含等待 |

默认显示 9 个区块，模型默认隐藏。最近请求入/出已合并到输入和输出区块，上下文下面依次为轮次/压缩、缓存占比；时间区依次为请求耗时、用时、跨度。右键「显示数据」勾选项目，「数据顺序」可上移、下移或移到最前；选择和顺序自动保存，也可以恢复默认显示和顺序。至少保留一项。

HUD 与右键菜单不显示悬停提示。“本次”只表示最后一次已记录的模型请求，一次用户提问可能包含多次请求，不按整轮累计。额度监听所有本机会话日志的变化，约每 200 ms 检查待处理通知，常规数据每秒补偿读取。没有新的服务器快照时，保留有效快照，过期后显示缺失。

## 跟随与操作

- 默认跟随当前窗口选中的本机会话。右键可以固定到某个会话，或恢复自动。
- 顶部显示 CLH，贴合左侧窄导航栏的内容区域，保留原生窗口边框。背景从侧栏四周的窄像素条采样并缓存，跟随横向和纵向颜色变化；名称按文字实际需要的高度换行，短名称自动收起空白，空间不足时收紧读数。
- 使用窗口位置事件跟随移动。切换其他应用仍保留，随 Codex 一起被遮挡；Codex 隐藏、最小化或关闭时隐藏。
- 默认锁定侧边栏，鼠标保持普通箭头。右键「解锁，自由拖动」后可以横向和纵向拖动；「锁定到侧边栏」重新贴合。解锁位置相对主窗口保存，窗口移动时继续跟随。宠物等透明工具窗口不会成为跟随目标。

## 数据与兼容

默认从 `%USERPROFILE%\.codex` 读取，支持 `CODEX_HOME`。会话选择依赖 Windows 无障碍接口；重名且无法可靠区分时，请右键手动固定。

便携包的 `portable.flag` 让配置保存在旁边的 `data/`。没有标记时使用 `%LOCALAPPDATA%\CodexLiteHud`；也可用 `CODEX_LITE_HUD_DATA_HOME` 指定数据目录。

HUD 不联网、不调用模型、不读取登录密钥，也不改写 Codex 的配置、日志或数据库。自己的状态文件可能包含会话名和用量，保留在本机。目录与读数边界见[数据说明](docs/DATA.md)。

Codex 的界面、日志和数据库格式不是本项目控制的稳定接口，升级后可能需要适配。数据库按 `state_<数字>.sqlite` 发现，归档查询只读；结构不兼容时仍保留手动选择入口。

## 开发与发布

在源码仓库中使用 Windows 自带的 .NET Framework 编译器，无 NuGet 运行依赖：

```powershell
.\scripts\build.ps1
.\scripts\test.ps1
.\scripts\release.ps1 -DryRun
```

`src/` 保存程序，`tests/` 保存回归，`assets/` 保存图标与清单。构建、中间文件和本机副本放在忽略的 `.local/`，干净发行包与 SHA-256 放在 `dist/`。发布流程见[开发与发布](docs/DEVELOPMENT.md)。

运行时缓存未变化的索引与字体测量，无新读数时跳过重绘，跟随位置与统计读取分开。性能口径和验证范围见[性能说明](docs/PERFORMANCE.md)。
