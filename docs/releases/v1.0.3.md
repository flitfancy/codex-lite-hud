Codex Lite HUD 1.0.3 试用版（2026-10-19）新增已安装字体选择，可将悬浮条和菜单一起切换到霞鹜文楷屏幕阅读版等字体。

- 右键「字体」选择字体，标题、说明文字、读数和菜单同步更新，选择自动保存，重启后继续使用。
- 字体偏好单独保存在 `data/appearance.json`，保留已有数据项目与顺序。菜单标注未安装字体；换到缺少该字体的电脑时自动回退。
- 复用系统字体，不捆绑字体文件，不增加后台刷新。字体切换后释放旧资源；窗口跟随和文字拟合使用同一字体缓存，避免反复重排。

下载 Assets 中的 `codex-lite-hud-1.0.3-win-x64.zip`，解压后双击 `CodexLiteHud.exe`。Source code 是源码包。升级时先退出旧 HUD，替换原目录中的程序与脚本，保留自己的 `data/` 设置。

使用霞鹜文楷屏幕阅读版时，请先在该电脑安装字体，再从 HUD 的右键「字体」菜单选择。字号规则与小屏幕布局策略沿用上一版，本次未调整笔记本上的整体显示大小。

新增字体回归 7 项全部通过，完整隔离回归 25 组通过，0 失败、0 跳过；干净 ZIP 文件集、SHA-256 与解压后运行检查通过。同条件字体对照未测到明显额外占用，测量口径见发行包内 `docs/PERFORMANCE.md`。

继续以 Pre-release 发布，不设为 Latest 稳定版。现场验证环境为 Windows 11 x64、.NET Framework 4.8 系列和本机 Codex Windows 桌面客户端。其他系统、客户端版本及 Free/Plus 真实账号现场验收范围保持不变。
