Codex Lite HUD 1.0.2 试用版（2026-10-17）修复日志变化后的统计恢复和受限高度下的标题布局，补齐最近请求读数，并统一文字显示。

- 会话日志归档、取消归档、截断或替换后，重新定位并恢复统计；保留半行续写和增量读取，不重复累计已经读过的记录。
- 补齐 `token_count` 中最近请求的输入与输出。新旧格式按记录时间合并，较旧记录不覆盖较新读数；新请求没有可用计时依据时，耗时和均速显示缺失，不沿用上一请求的速度。
- 额度启动扫描先对日志路径去重，再选择最近修改的文件，避免重复路径占用扫描名额而漏掉有效快照。
- 侧栏可用高度受限时，切换长短会话名称也会重新分配标题和读数的位置，修复总高度不变时仍沿用旧布局造成的标题裁切。
- 放大并加粗正文与读数。说明文字使用同一字号，用时、跨度、上下文容量和其他可见读数使用另一统一字号；按可用标签空间分组适配，保留多 DPI 与紧凑布局的像素边界保护。
- 按启动入口、数据读取、窗口跟随、界面呈现和刷新协调整理源码职责；指标名称、行高及标签槽位集中管理，减少布局、清空、字体和主题各自维护名单的重复。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install-shortcuts.ps1 -WithCodex
```
